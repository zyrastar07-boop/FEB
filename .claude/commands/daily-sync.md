# /daily-sync

Run the morning briefing:

1. Read `data/logs/` and identify the most recent session.
2. Check project status: `git status`, pending PRs, and CI health.
3. Review `data/inbox/` for new tasks or decisions needed.
4. Generate a summary of blockers, priorities, and next actions for today.
5. Append the briefing to `data/logs/daily/<date>.md`.
